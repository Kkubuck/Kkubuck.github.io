[문제 보기](https://www.acmicpc.net/problem/11650)

2차원 평면 위의 점 N개(1 ≤ N ≤ 100,000)를 x좌표가 증가하는 순으로, x좌표가 같으면 y좌표가 증가하는 순으로 정렬해 출력한다.

## 풀이

파이썬의 튜플은 첫 번째 원소부터 차례로 비교한다. 좌표를 `(x, y)` 튜플로 저장해 정렬하면 x가 같을 때 자동으로 y를 비교하므로 조건이 그대로 만족된다.

```python
import sys

n = int(sys.stdin.readline())
points = []

for _ in range(n):
    x, y = map(int, sys.stdin.readline().split())
    points.append((x, y))

points.sort()
for x, y in points:
    print(x, y)
```

입력이 최대 10만 줄이므로 `input()`보다 `sys.stdin.readline()`으로 읽는 편이 빠르다.
