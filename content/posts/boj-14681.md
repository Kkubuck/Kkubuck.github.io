[문제 보기](https://www.acmicpc.net/problem/14681)

정수 x, y(−1000 ≤ x, y ≤ 1000, 둘 다 0이 아님)가 한 줄에 하나씩 주어질 때, 점 (x, y)가 속한 사분면 번호를 출력한다.

## 풀이

x와 y의 부호 조합으로 사분면이 정해진다.

| x | y | 사분면 |
| --- | --- | --- |
| 양수 | 양수 | 1 |
| 음수 | 양수 | 2 |
| 음수 | 음수 | 3 |
| 양수 | 음수 | 4 |

```cpp
#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;

    if (x > 0 && y > 0) cout << 1;
    else if (x < 0 && y > 0) cout << 2;
    else if (x < 0 && y < 0) cout << 3;
    else cout << 4;

    return 0;
}
```

좌표가 0이 아니라는 조건이 있으므로, 앞의 세 경우가 아니면 4사분면이다.
