[문제 보기](https://www.acmicpc.net/problem/15596)

정수 n개가 담긴 리스트 `a`(1 ≤ n ≤ 3,000,000)가 주어질 때, n개의 합을 돌려주는 함수 `solve(a)`를 작성한다. 입력과 출력을 직접 처리하지 않고 함수만 제출하는 형식이다.

## 풀이

파이썬 내장 함수 `sum()`을 쓴다.

```python
def solve(a):
    return sum(a)
```
